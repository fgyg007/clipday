# 轻贴统一入口 · 0.2.0-dev

这是未发布、未通过原生编译与真机验收的集成源码，不是新安装包。Mac / Windows 在同一个轻贴入口中选择仅本机、NAS 或网盘文件夹；Android 当前仅支持 NAS。需要手机参与请选择 NAS；只用本机历史请选择仅本机；电脑间有现成双向云盘同步时可选择网盘文件夹。每次进程只启用一种模式。切换会停止记录及传输、保留原模式数据，按提示手动重启，不自动迁移或补传旧历史。

网盘文件夹模式复用已登录的云盘客户端维护的本地双向同步文件夹，不调用百度、Microsoft 或 Apple API，不包含 OAuth、服务器、账号或令牌。界面列出百度网盘、OneDrive、iCloud 和其他同步文件夹，只用于提示配置来源，不代表已经验证各家或所有版本都兼容。百度 API 实验已暂停，不在本产品构建中。

## 首次使用

1. 自行安装、登录云盘客户端，并确认两台电脑能双向同步同一个文件夹。单向备份、仅网页下载、虚拟盘挂载不能直接视为符合条件。
2. 将该文件夹及子文件设为完整保留在本机。占位文件、未下载的图片分块、云端冲突副本都可能延迟接收。
3. 在轻贴中选择网盘文件夹模式并指定该文件夹，各电脑本机路径可以不同。界面检查只能证明本机读写，不证明云端或另一台就绪。
4. 首台创建空间，在第二台手动输入第一台显示的完整秘密配对信息。它包含256位加密密钥，只向你要加入的设备安全传递，切勿存进同步文件夹或发给不可信的人。没有自动复制密钥按钮，应用会过滤自身格式的配对令牌，避免误入剪贴板同步。
5. 等云盘客户端传完空间文件。第二台只有验证加密证明后才连接；缺失/不完整文件会等待重试，不擅自创建另一份空间。
6. 用无敏感内容的文字和小图片分别测试双向同步、暂停与恢复。不是即时通道，不能保证秒到。

OneDrive 官方说明：[Files On-Demand](https://support.microsoft.com/en-us/onedrive/save-disk-space-with-onedrive-files-on-demand-for-windows)。百度个人网盘官方首页介绍同步空间：[百度网盘](https://wangpan.baidu.com/)。具体 Mac/Windows 客户端及套餐条件须自行核对；本次没有登录真实账号或更改同步/保留设置。

## 安全及行为

- 云盘目录只写加密文字、图片分块与认证证明，公开空间标识不包含密钥。配对密钥保存在 Mac 钥匙串 / Windows DPAPI 保护的本地配置中。云盘模式的设置、历史和队列与 NAS 模式隔离，应用本身沿用原 NAS 身份以避免升级丢失旧数据。
- 独立远端目录 `ClipDayDrive/v1/<space>`；不复用或迁移 NAS `ClipDaySync`。
- 每条记录独立不可变标识，不写共享数据库或覆盖式 latest 文件。分块按认证及完整性校验后才接收；本机原子替换不等于云端整体原子事务。
- 写入本机云盘文件夹不代表已上传，更不代表另一台已收到。界面始终把这些未知状态分开。
- 文字/图片自动同步；首轮与重连只补历史，不覆盖当前剪贴板。云盘模式最多接受5分钟内且未被本机较新活动淘汰的自动接收，超过窗口仍可进入24小时历史。冲突或不完整批次不强行自动粘贴。
- 隐私暂停停止轻贴的捕获、收发和接收端剪贴板写入，但不能撤回已经写进文件夹的密文，也不能暂停独立运行的云盘客户端。云盘垃圾箱、版本历史和离线副本可能比24小时更久保留密文；没有云端删除确认或远程销毁承诺。
- 只支持已有文字与受限PNG图片协议；不是任意文件传输器。图片20MiB / 1600万像素限制不变。
