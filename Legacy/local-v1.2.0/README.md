# 轻贴 · ClipDay

**给 macOS 加一个保留 24 小时的剪贴板历史。复制、找回、直接粘贴，需要留下的内容一键存到下载。**

[English](README.en.md) · [下载 DMG](https://github.com/fgyg007/clipday/releases/latest) · [安装指南](docs/INSTALL.md) · [反馈问题](https://github.com/fgyg007/clipday/issues)

## 它能做什么

轻贴是一个用 Swift / SwiftUI 编写的菜单栏工具。你照常使用 `⌘C`、`⌘V`，它在后台记录复制过的文字和图片。需要旧内容时打开历史，搜索并点击记录，返回之前选中的窗口粘贴，无需来回切换复制。

| 功能 | 行为 |
| --- | --- |
| 剪贴板历史 | 记录文字和 PNG/TIFF 图片；富文本保存为纯文字 |
| 24 小时滚动清理 | 每条从复制时独立计时，到期删除；退出或休眠期间无法清理，重新打开时补清理 |
| 直接粘贴 | 点击历史后回到此前的应用执行粘贴，需要辅助功能权限，不发送回车 |
| 自定义全局快捷键 | 默认 `⌃⌥V`（Control + Option + V），可在设置中录制新组合 |
| 快捷键冲突检查 | 检查已启用的系统快捷键，并尝试独占注册检测全局占用 |
| 搜索 | 搜索文字历史 |
| 保存到下载 | 文字导出 TXT、图片导出 PNG；导出的文件不受历史到期影响 |
| 后台使用 | 关闭历史窗口后继续记录，可暂停、恢复或设置登录启动 |
| 本机保存 | 无账号、无同步服务、无遥测，不上传剪贴板 |

## 运行环境

- **Apple Silicon Mac（M 系列）**，**macOS 14 Sonoma 或更新版本**。
- 本次 DMG 仅包含 **arm64**，不支持 Intel Mac、Windows 或 Linux。
- 应用界面为**简体中文**；项目文档提供中英文。
- 运行无需 Xcode、Python 或其他开发工具，无需联网。
- 最低部署目标为 macOS 14；实际运行验证在 Apple Silicon / macOS 27.0.1 完成，未覆盖每个系统版本。

## 下载与开始使用

1. 前往 [最新版本](https://github.com/fgyg007/clipday/releases/latest)，下载 `ClipDay-1.2.0-arm64.dmg`。
2. 打开 DMG，把 `轻贴.app` 拖到 **Applications**；推出 DMG，再启动安装后的应用。
3. 复制一段文字，打开菜单栏的轻贴图标，或者按 `⌃⌥V` 查看历史。
4. 要直接粘贴：在**系统设置 → 隐私与安全性 → 辅助功能**中允许轻贴。先点击目标输入框，再按快捷键打开轻贴，点击所需记录。
5. 要保留内容：点击记录右侧的保存图标，文件会写入当前用户的“下载”文件夹。右键记录可选择“仅复制，不粘贴”。

**发布包采用 ad-hoc 签名，尚未经过 Apple Developer ID 签名或公证。**首次打开可能被 macOS 阻止；请阅读[安装指南](docs/INSTALL.md)核验来源、校验值和系统“仍要打开”的操作方法。

## 权限与常见问题

- **复制记录与直接粘贴是两项功能。**读取剪贴板受 macOS 粘贴访问设置控制；自动切回目标并粘贴需要辅助功能权限。若系统询问粘贴访问，请允许。
- **更新后开关已开，却提示未授权：**当前采用 ad-hoc 签名，新构建可能改变系统识别的签名。退出应用，在辅助功能列表移除旧项，再添加安装目录里的当前应用并开启。避免保留多个副本。
- **点历史只复制、不自动粘贴：**检查辅助功能授权，确认目标应用有可编辑输入框；若目标退出、焦点被切到第三个应用、剪贴板又改变或修饰键未松开，自动粘贴会取消并提示。
- **窗口隐藏后应继续记录。**如果没有记录，检查是否暂停、是否退出了应用、系统粘贴访问、内容类型和大小。若仍有问题，请反馈来源软件、系统版本和步骤，勿附私人剪贴板正文。
- **不能保证所有快捷键冲突都能检测。**应用内快捷键、独立按键监听和将来发生的占用无法完整枚举；冲突时可换组合，或从菜单栏打开。

## 数据和限制

- 每条最多 **20 MiB**，总计最多 **200 MiB / 2,000 条**；超限淘汰最早记录。重复复制同一内容更新时间，点击旧记录不延长保留期。
- 不记录 Finder 文件复制，不保留原始富文本排版，不提供跨设备同步。
- 跳过来源应用标记为私密、临时或自动生成的内容。**未标记的密码仍可能被记录**，处理敏感信息前可暂停。
- 历史保存在 `~/Library/Application Support/io.jlmac.ClipDay/`，内容仅本机保存，**未另行加密**。目录权限 700，索引与内容文件权限 600。
- 历史到期或清空历史不会清除系统当前剪贴板、已导出的文件，也不会移除系统备份中的副本。
- 轮询间隔约 0.6 秒，快速连续复制可能覆盖尚未采集的内容。自动粘贴依赖目标应用接受标准 `⌘V`。

## 从源码构建

```sh
git clone https://github.com/fgyg007/clipday.git
cd clipday
zsh scripts/test.sh
zsh scripts/build.sh
zsh scripts/package.sh
```

开发依赖、构建产物、打包与贡献方式见[开发说明](docs/DEVELOPMENT.md)。核心测试使用临时目录与独立命名剪贴板。

原生集成测试会操作临时输入窗口及实际安装的轻贴，并暂时使用系统剪贴板，只应在主动测试时运行：

```sh
zsh scripts/build-e2e.sh
build/e2e-test --background-idle
```

测试需安装轻贴到 `~/Applications` 或 `/Applications`，测试进程和轻贴均需辅助功能权限，且快捷键设置已保存。执行期间不要操作其他窗口或复制真实内容；测试结束尽力恢复原剪贴板并清理生成记录，保留期间发生的新复制。它不属于普通安装流程。

## 验证状态

v1.2.0 的核心检查覆盖延迟剪贴板数据交付、连续复制与历史选择、到期、导出、快捷键和粘贴条件。实际安装版本通过原生文字窗口流程，包括隐藏窗口 75 秒后继续采集、点击历史直接粘贴和后续新复制。尚不代表所有第三方编辑器、图片接收程序或旧系统均通过验证；已报告过后台漏记现象，但未在上述文字窗口流程中复现。
