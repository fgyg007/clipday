# 轻贴 NAS 版 · NAS 预览版

> 当前集成源码统一显示为“轻贴”，桌面可选仅本机、NAS、网盘文件夹；Android仅支持NAS。下文原发布包名称/版本是历史安装信息，未发布新包。完整模式引导与未完成的历史迁移见 [统一说明](../Desktop/README.md) 和 [合并计划](CONSOLIDATION.md)。


当前源码使用“轻贴 NAS 版”显示名，尚未发布。下文描述现有发布包（Mac 0.1.1 / Windows 0.1.3 / Android 0.1.0），其旧显示名称和文件名保持不变。当前源码构建的 Mac 为 `轻贴 NAS 版.app`，Windows 仍运行 `ClipDay.Cloud.exe`；应用标识、存储、配对与 NAS 协议不变，Android 继续支持 NAS。

NAS 版提供 Mac 与 Windows 之间的加密纯文字同步。无需轻贴账号，也不连接开发者的服务器。两台电脑必须能读写同一个 NAS 文件夹。

Android 0.1.0 已加入同一空间的主动收发：分享文字到轻贴后确认发送，打开轻贴查看历史并手动复制。手机填写 NAS 地址、共享名称、子文件夹与 NAS 账号，使用电脑显示的 6 位配对码加入；电脑不用升级。范围为同一 Wi-Fi／可互通的局域网，不提供移动网络或后台剪贴板同步。安装、构建与手机限制见 [Android 使用说明](../Android/README.md)。

这是单独的应用：Mac 名为“轻贴云版”，独立保存设置和历史，不迁移或覆盖本地版 v1.2.0。Windows 为 x64 托盘程序，随包附带 .NET 运行环境，解压即可启动。Mac 为 ad-hoc 签名且未公证，Windows EXE 未做 Authenticode 签名。桌面功能已有维护者实际试用反馈，尚未覆盖所有系统与 NAS 组合；安卓用户真机与实际 NAS 仍待验收。

## 开始使用

1. Mac 打开 NAS 共享，选择一个专供轻贴使用的文件夹；确认 Windows 也能打开并在其中创建文件。两台电脑显示的路径通常不同。
2. Mac 启动“轻贴云版”，打开设置，在“NAS 文件夹路径”填写已挂载的完整路径（如 `/Volumes/共享/轻贴`），也可以点“浏览…”选择，然后点击“创建同步空间…”。应用会建立 `ClipDaySync/<空间 ID>/`，不会扫描共享中的其他文件。
3. Mac 会显示随机 6 位数字，按 `123 456` 分组，右侧圆环和时间显示剩余有效期（2 分钟）。在另一台电脑手动输入即可，生成数字不会改写剪贴板。若已创建空间，点“配对另一台电脑…”生成数字，无需再建空间。
4. Windows 解压整个 ZIP，运行 `ClipDay.Cloud.exe`，在路径框填写同一份 NAS 文件夹的 Windows 路径（如 `\\NAS\共享\轻贴` 或 `Z:\轻贴`，也可浏览选择），点“输入配对码”，输入 Mac 显示的 6 位数字。不要在 Windows 再创建第二个空间。配对成功后数字立即失效；过期或累计输错 5 次后，在首台电脑点“重新生成配对码”。
5. 等两端显示 NAS 已连接，在 Mac 复制一小段测试文字，等约 2–3 秒，在 Windows 的记事本按 `Ctrl+V`；反向复制后在 Mac 按 `⌘V`。
6. Windows 关闭窗口后继续在托盘运行，双击托盘图标可打开历史。右键托盘选择“退出”才停止运行。Mac 云版快捷键为 `⌃⌥⇧V`（Control + Option + Shift + V），与本地版区分。

路径可以由用户自行填写，无需提供给开发者。两端填的是各自系统访问同一文件夹的路径，不要求字符串相同。Mac 的 `smb://` 地址须先在访达中连接，再填写 `/Volumes/…` 的挂载路径。编辑路径框不会立即切换连接，需点击创建／加入；无效或不可访问的路径会提示错误。

从 0.1.0 升级时，两台电脑都需要更新到 0.1.1 或更新版本才能用 6 位数字配对。已有同步空间和密钥继续可用，不必重新创建。也可以由 Windows 创建空间并显示数字，Mac 输入加入。同一共享文件夹同时只保留一个有效配对邀请。

Windows 0.1.2 更新了浅色界面、来源和时间分行的历史列表、程序／托盘图标，以及适应屏幕缩放的配对弹窗和倒计时。Mac 0.1.1 可继续使用，不需要重新配对。更新 Windows 时先退出旧程序，再解压新版到新文件夹并运行；配置和历史保存在当前用户的数据目录中，会继续读取。若右下角没有看到图标，先检查托盘折叠区（小箭头）；Windows 可能把新图标收在那里。

Windows 0.1.3 修复成功后因清理临时文件出错或旧操作迟到而误报失败的路径；配对成功后不会被同一次操作的过期／失败回调覆盖。默认窗口客户区从 860×740 调整为 860×880（随 DPI 缩放，并限制到屏幕工作区）。连接成功后自动收起路径和配对按钮，点“连接设置”可展开；文字历史保留最小显示高度，成功提示也缩短，减少对历史区域的挤占。

先用测试文字验收。Mac 如询问粘贴访问，需要允许读取剪贴板；“收到后按 ⌘V”无需辅助功能权限，点击 Mac 历史后自动切回目标应用粘贴则需要为“轻贴云版”单独授权。Windows 默认不申请管理员权限，便携版尚不自动登录启动。

## 已实现的行为

- 每约 2 秒检查共享目录，最多同步 1 MiB 的 UTF-8 纯文字，保留来源设备与原始 24 小时过期时间。
- AES-256-GCM 加密，每条一个随机 nonce 与独立文件，校验格式与认证标签后才读取。Mac 密钥存系统钥匙串，Windows 配对信息由当前 Windows 用户的 DPAPI 保护。
- 配对通过 SRP-6a 密码认证交换加密传递空间密钥。6 位数字只用于短期配对，NAS 不保存明文数字、密码校验值或明文空间密钥；它不是文字加密密钥。
- 本机复制后先写入加密待发送队列。NAS 离线时本地记录继续，重连自动重试；不会在缺失的挂载点下创建“假的 NAS”目录。
- 首次连接、重启、暂停恢复及超过 6 秒未成功检查后的第一轮，只导入历史。接收新记录不会再上传，去重与计数器跨重启保存。
- 连续连接时，只有生成不超过 10 秒、来源序号更新且已经观察到本机最近一次已入队复制的记录才可自动写剪贴板。两边同时复制时保留历史；跨多个来源的同时到达也保守地只进历史。
- NAS I/O 在后台执行。返回时再检查本机剪贴板版本与操作状态，防止慢响应覆盖刚复制的文字。手动选历史、私密或不支持的内容会短暂保护当前剪贴板。
- 不完整／被篡改文件不进入历史；下次继续尝试完整文件。无效文件不自动删除其他用户数据。
- 已收到但尚未成功保存到历史的记录保存在本机加密收件箱，保存成功后确认并清除；重启可以恢复，已确认或本机删除的历史不会因同一个同步文件又出现而重新导入。

## 当前边界

- 第一版仅同步文字。Mac 图片仍保存在本机；Windows 预览版只记录文字。快速连续复制仍可能在系统交付前被下一条覆盖，不保证每次瞬间复制都被捕获。
- NAS 状态表示共享目录可访问，不代表另一台电脑正在运行。同步延迟受 SMB、网络和设备休眠影响。
- 时钟相差较大时保守地只进历史或拒绝记录；建议两台设备启用系统自动时间。未来时间超过 5 分钟的记录会等待重试；未来时间不会自动写剪贴板。
- Windows 历史支持搜索、手动复制、清空，暂没有全局历史快捷键、直接向其他窗口发粘贴键、安装器、更新器或登录启动。
- 本机删除只删除本机历史，不传播“全设备撤回”；NAS 上的记录在到期后由运行且连接着的客户端清理。没有在线客户端、暂停同步或目录不可写时，清理会延后；快照、回收站和备份不受应用控制。
- Mac 本机历史仍为原本的未加密存储，Windows 本机历史使用 DPAPI。同步目录只存密文和非秘密的空间标识；文件数量、大小、时间与访问模式并不隐藏。
- 能读写该共享文件夹并在有效期内输入正确数字的设备可以加入空间并解密历史；只向自己的设备展示数字。第一版没有撤销单个设备或自动密钥轮换：需要换密钥时创建新空间并为保留的设备重新配对。丢失所有已配对设备及其保存的密钥后无法恢复密文，过期的 6 位数字不能用于恢复。
- 队列最多 2,000 条／约 100 MiB；超过限制提示仅留本机。Mac 本机历史上限仍为 2,000 条／200 MiB，Windows 为 2,000 条／100 MiB。
- 不自动启用真实 NAS 同步；首次使用由用户在两端选择目录和配对。切换空间不自动搬迁旧队列与旧历史。

## 构建与验证

Mac 云版构建除本地版的工具链外，还需要 .NET 10 SDK 编译原生配对组件；用户安装后不需要另装 .NET。Windows 也使用 .NET 10 SDK，可在 Mac 交叉编译 Windows x64 程序。两端共用 BouncyCastle.Cryptography 2.6.2 的 SRP-6a 实现，许可证随应用附带。

```sh
zsh scripts/test.sh
zsh scripts/test-cloud.sh
zsh scripts/build-cloud.sh
zsh scripts/test-pairing-bridge.sh
zsh scripts/build-windows.sh
```

若 `dotnet` 不在 PATH，设置 `CLIPDAY_DOTNET=/absolute/path/to/dotnet` 后执行相应脚本。测试使用临时文件夹、合成文字、固定公开测试密钥和独立命名剪贴板，不使用个人 NAS 数据或系统剪贴板。Windows 同步核心可在 Mac 上测试；Windows Forms、DPAPI 和真实 Windows 剪贴板仍需 Windows 真机验收。

协议见 [CLOUD-PROTOCOL.md](CLOUD-PROTOCOL.md)。初次联调应覆盖：双向中文和多行文字、连续复制、同时复制、NAS 断线重连、两端重启、暂停恢复、Windows 托盘关闭与退出，以及两端时钟偏差。实际共享文件夹未确认前，不把本机目录测试写成 NAS 真机验收通过。

Windows 0.1.3 已有维护者试用反馈。新增 9 项配对结果／迟到回调／清理失败回归通过，原有 19 项短码配对与 22 项 C# 同步测试通过；未穷尽所有 Windows 版本与缩放设置。布局按 [WinForms 自动缩放机制](https://learn.microsoft.com/en-us/dotnet/desktop/winforms/forms/autoscale) 使用 DPI 基准、自动行高和内容自适应按钮，代替配对弹窗的固定坐标。
